# Homework Assignments

*   **`hw00`: Binary Numbers**
    Modeling binary numbers using recursive data structures and implementing fundamental arithmetic operations.
*   **`hw01`: Functional Matrices & Tic-Tac-Toe**
    Building a custom matrix library using higher-order functions and applying it to evaluate Tic-Tac-Toe game states.
*   **`hw02`: AST Transpiler & Optimization**
    Extending an expression evaluator with variable contexts, building a transpiler to Racket, and implementing constant folding optimization.
