# Functional Programming - FMI (2024–2025)

This repository contains all my coursework for the *Functional Programming* course at the Faculty of Mathematics and Informatics (FMI), Sofia University.

## Contents
- **Homework assignments** – practical assignments applying core functional programming principles.
- **Seminar exercises** – code solutions for the weekly in-class tasks.

## Structure
- `homeworks/` – all homework assignments (built as independent Cabal projects in Haskell).
- `seminars/` – solutions to weekly seminar tasks (in Haskell and Scheme).

## Technologies
- **Scheme** (Racket)
- **Haskell**
- **Cabal** (Build tool & Testing)
